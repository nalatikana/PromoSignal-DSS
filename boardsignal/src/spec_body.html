ขั้นตอนงานสิ่งที่ระบบให้

ยกระดับ Board Evaluation จาก qualitative ล้วน เป็น quantitative + qualitative และเชื่อมเรื่องธรรมาภิบาลเข้ากับ open innovation ซึ่งเป็นวาระของตลาดทุนไทย

ข้อห้ามที่ต้องติดไปกับทุกผลลัพธ์ — ระบบอธิบายคุณสมบัติเชิงโครงสร้างของคณะกรรมการ ไม่ใช่การชี้ตัวบุคคล · ห้ามนำไปใช้ให้คะแนนหรือคัดกรองกรรมการรายบุคคล เพราะเพศ อายุ และความเชื่อมโยงทางการเมืองเป็นข้อมูลอ่อนไหวตาม PDPA มาตรา 26 · ระบบจึงไม่ตั้ง “กรรมการสายนโยบาย” เป็นเป้าหมายในการสรรหา แม้สัมประสิทธิ์ในโมเดลจะเป็นบวก

4 · MVP Phase I — สิ่งที่ต้องมีในรอบนำเสนอนี้

ต้องมี

  • ระบบสมาชิก ยืนยันตัวตน และ consent สำหรับข้อมูลและเอกสารที่อัปโหลด
  • Token unlock — Free user 3 tokens · Paid user 20 tokens
  • ปรับ token ด้วยมือได้สำหรับการสาธิต โดยยังไม่เชื่อมการชำระเงินจริง
  • รายงานเทียบอุตสาหกรรม และเทียบคู่แข่งรายบริษัทไม่เกิน 3 ราย ข้ามกลุ่มอุตสาหกรรมได้
  • อัปโหลดเอกสาร → นับภาษา → สรุปข้อค้นพบ → ออกรายงาน

กติกา Free / Paid ที่ทำไว้ในต้นแบบ

  • รายงานบริษัทของตัวเอง ฟรีเสมอ (บริษัทแรกที่เปิดคือบริษัทของผู้ใช้)
  • รายงานฉบับเต็มของบริษัทอื่น 1 token ต่อบริษัท ปลดล็อกแล้วดูได้ตลอด
  • เทียบคู่แข่งสูงสุด 3 ราย 1 token · เปลี่ยนคู่เทียบได้ไม่จำกัดหลังปลดล็อก
  • รายงานระดับอุตสาหกรรมพร้อมส่งออก CSV 3 tokens
  • ซื้อ token ขั้นต่ำ 3 tokens ต่อครั้ง · Pro plan เป็นแบบ token-based
  • ข้อควรระวังเรื่องความแม่นไม่เคยถูกซ่อนหลังผนังจ่ายเงิน — ผู้ใช้ฟรีเห็นสรุปครบ ส่วนที่ต้องจ่ายคือรายละเอียดรายปี

Design principles ที่ใช้จริงในหน้า

  • เรียงบนลงล่างตามลำดับงานจริง ไม่ใช่ตามโครงสร้างเทคนิค
  • หนึ่ง action หลักต่อหนึ่งโซน ปุ่มรองอยู่ต่ำกว่าเสมอ
  • บริบทบริษัทค้างไว้ด้านบนตลอด
  • หัวข้อโซนเป็น sticky header เมื่อเลื่อน จึงไม่หลุดว่าอยู่โซนไหน
  • สลับ TH / EN โดยตั้งค่าเริ่มต้นเป็น EN
  • สีแบรนด์คุมเฉพาะส่วนตกแต่ง สีที่แทนข้อมูลเป็นชุดตายตัวที่ผ่านการตรวจตาบอดสีแล้ว

Supporting elements

  • Floating action bar — Generate Full Report · Save Scenario · Export Candidate Brief
  • Activity timeline แบบลิ้นชัก เก็บประวัติ upload / แก้ค่า / ปลดล็อก / ส่งออก
  • สลับ Analysis Mode และ Presentation Mode ได้จากปุ่มเดียว
  • บนจอประชุมและแล็ปท็อป โซนจะเรียงต่อกันแนวตั้งพร้อมหัวข้อค้างด้านบน
  • เอกสารที่ออกได้ — Candidate Brief และ Board Memo พิมพ์เป็น A4 ได้ทันที

8 · สิ่งที่ยังรอการตัดสินใจ

  1. CI ของแบรนด์ — สี ชื่อระบบ และโลโก้ · ต้นแบบใช้ชุด AN · RC ไปก่อน
  2. นิยาม Innovation Intensity และรายชื่อตัวแปรอิสระชุดใหม่ ยังรอยืนยัน
  3. การแสดงชื่อบริษัทจริง — ต้นแบบแสดงชื่อจริงเพราะการเทียบคู่แข่งจะไม่มีความหมายถ้าไม่มีชื่อ ควรปรึกษาฝ่ายกฎหมายก่อนเปิดสาธารณะ
  4. งบประมาณ — ตัวเลข 58,000 บาทรวมงานออกแบบที่ระบุไว้ในร่างเดิม ยังไม่ได้ยืนยันร่วมกัน
  5. วันล็อกขอบเขต — ถ้าจะรักษาวัน user testing เดือนธันวาคม ขอบเขตต้องถูกล็อกในที่ประชุมรอบนี้ ทุกฟีเจอร์ที่เพิ่มหลังจากนั้นจะดันวันทดสอบออกไป จึงควรใช้ที่ประชุม ตัดออก มากกว่าเพิ่มเข้า
