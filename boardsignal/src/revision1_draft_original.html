Flow ระบบ

ลำดับหน้าจอเรียงจากงานจริงของผู้ใช้ ไม่ใช่จากโครงสร้างเทคนิค

1

Upload Documents

ผู้ใช้เพิ่ม 56-1, Annual Report, CEO Letter หรือ Transcript แล้วระบบดึงตัวแปรบอร์ดและข้อความ CEO

2

Generate Insights

โมเดลคำนวณ OI Score พร้อมสรุป Strength, Constraint, Opportunity และ Risk เป็นภาษาคนใช้งาน

3

Recommend Action

จัดลำดับข้อเสนอ Board Refresh, สร้าง Candidate Brief, Board Memo หรือ Report สำหรับประชุม

Algorithm ใน Assessment Tools

อธิบายการเชื่อม Predictive Model ให้คนประชุมเห็นภาพโดยไม่ลงรายละเอียดโค้ด

ช่วงงานสิ่งที่ระบบทำสถานะใน Prototype
Jan-May หลัง Annual Report ออกFetch/Scrape One Report จาก SET แล้วจัดเป็น Structured Excelออกแบบไว้ / Phase II
Structured Excel 5 ปีใช้ข้อมูลที่มีอยู่เป็นฐานเริ่มต้นสำหรับ prototypeใช้ใน Phase I
STATA / R Modelแปลผล coefficient, adjust regression equation, moderation analysisเชื่อมแนวคิดแล้ว
Validationเช็ค Spearman, AUC, Decile Lift, LOYO แล้วสรุประดับอ้างอิงแสดงใน Validity
Resultออก OI Score, Insight, Recommendation และ What-if Scenarioโฟกัสของ Phase Prototyping

MVP Prototype Phase I

สิ่งที่ต้องมีในเวอร์ชันนำเสนอรอบนี้

ต้องมี

  • ระบบสมาชิก ยืนยันตัวตน และ consent สำหรับข้อมูล/เอกสาร
  • Token unlock: Free user 3 tokens, Paid user 20 tokens
  • Manual token adjustment สำหรับ demo โดยยังไม่เชื่อมชำระเงินจริง
  • รายงานเทียบอุตสาหกรรม และเทียบคู่แข่งรายบริษัทไม่เกิน 3 ราย ข้าม sector ได้
  • Upload เอกสาร, NLP extraction, สรุป insight, สร้าง report

กติกา Free / Paid

  • Free user ดูรายงานบริษัทตัวเองได้ฟรี
  • การดู peer report หรือรายงานระดับประเทศต้องใช้ token
  • ซื้อ token ขั้นต่ำ 3 tokens สำหรับการปลดล็อกส่วนเปรียบเทียบ
  • Paid user เห็นรายละเอียด What-if Studio และ Validity Result มากกว่า Free user
  • Pro Plan เป็น token based คล้าย Claude

Design Principles

  • เรียงบนลงล่างตาม workflow จริง
  • หนึ่ง action หลักต่อหนึ่ง zone
  • company context ค้างไว้ด้านบนเสมอ
  • ลำดับภาพชัด: Upload → Insights → Recommendation
  • มี toggle TH/EN โดย prefer EN ก่อน

Supporting Elements

  • Floating action bar: Generate Full Report, Save Scenario, Share, Export Candidate Brief
  • Activity timeline แบบ drawer สำหรับประวัติ upload / insight / recommendation
  • Quick switch ระหว่าง Analysis Mode และ Presentation Mode
  • Laptop / meeting screen ให้ zone stack แนวตั้งพร้อม sticky section headers
