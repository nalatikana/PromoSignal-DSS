# PromoSignal DSS — ต้นแบบระบบสนับสนุนการตัดสินใจ

ระบบ 3 ขั้นตอน: **อัปโหลดเอกสาร → โมเดลวิเคราะห์ → แดชบอร์ดและรายงาน**

| ในขอบเขต | นอกขอบเขต |
|---|---|
| ให้คะแนนจากเอกสาร · จัดอันดับ · board-fit simulator · ส่งออกรายงาน | ระบบ production · บัญชีผู้ใช้ · การเชื่อมข้อมูลสด |

---

## ใช้งานได้ 2 แบบ

### แบบที่ 1 — เปิดไฟล์เดียว ไม่ต้องติดตั้งอะไร

เปิด `out/PromoSignal_DSS.html` ด้วยเบราว์เซอร์ใดก็ได้ ทุกอย่างทำงานในเครื่อง
เหมาะกับการสาธิตในที่ประชุม ส่งไฟล์ให้คนอื่น หรืออัปขึ้นเว็บโฮสต์ใดก็ได้ (เป็นไฟล์ static ไฟล์เดียว)

### แบบที่ 2 — รัน FastAPI เพื่อเชื่อมโมเดล Python จริง

```bash
pip install -r dss_api/requirements.txt
python3 src/export_dss_model.py      # ฟิตโมเดลและส่งออกสัมประสิทธิ์ (ทำครั้งเดียว)
python3 src/build_dss.py             # ประกอบหน้าเว็บ
uvicorn dss_api.app:app --reload --port 8000
```

เปิด <http://127.0.0.1:8000> · เอกสาร API อัตโนมัติที่ <http://127.0.0.1:8000/docs>

> ฝั่งเบราว์เซอร์และฝั่ง Python ใช้สัมประสิทธิ์ชุดเดียวกันและให้ผลตรงกันทุกหลัก
> (ตรวจแล้ว: ชุดโมเดล B ได้ 2.4013 · ชุดโมเดล A ได้ 1.8218 เท่ากันทั้งสองฝั่ง)

## Endpoint

| Method | Path | ทำอะไร |
|---|---|---|
| GET | `/` | หน้าเว็บ DSS |
| GET | `/api/health` | ตรวจสถานะ |
| GET | `/api/model` | สัมประสิทธิ์ ค่า p ช่วงข้อมูล และค่ากลางรายอุตสาหกรรม |
| POST | `/api/extract` | อัปโหลด PDF/DOCX/TXT → สารผู้บริหาร + คะแนนภาษา + จำนวนนวัตกรรม |
| POST | `/api/predict` | ค่าที่กรอก → ค่าคาดการณ์ + CI 95% + เปอร์เซ็นไทล์ + quintile + ความไวรายตัวแปร |
| POST | `/api/rank` | รายการผู้สมัคร → จัดอันดับ + นับว่าอันดับเปลี่ยนกี่รายเมื่อสลับชุดโมเดล |
| POST | `/api/report` | รายการผู้สมัคร → รายงาน HTML |

## ชุดโมเดล 2 ตัว — และทำไมต้องมีสองตัว

| | ชุดโมเดล A | ชุดโมเดล B |
|---|---|---|
| ที่มา | ตามสเปกใน `Pitch2.pptx` | ตามผลที่รันได้จริงจากข้อมูล |
| สมการ | `exp(β₀ + β₁·Promo + β₂·%Female + β₃·PolTie + β₄·Promo×%Female + β₅·Promo×PolTie + controls)` | `exp(β₀ + β₁·Promo + β₂·%Female + β₃·Tenure + β₄·Indep + β₅·BoardSize + β₆·PolTie + controls)` |
| ตัวขยายผลมีนัยสำคัญไหม | **ไม่** — Promo×%Female p = 0.802 · Promo×PolTie p = 0.267 | — |
| ตัวแปรที่มีนัยสำคัญ | ln สินทรัพย์ (p = 0.013) เท่านั้น | อายุงานบอร์ด p = 0.001 · กรรมการอิสระ p = 0.001 · ขนาดบอร์ด p = 0.006 |
| pseudo R² | 0.0382 | 0.0487 |

**สเปกใน Pitch2.pptx เขียนไว้ว่า** _"β₄, β₅ > 0 และ significant → Simulator ใช้สองตัวนี้ขยายผลได้อย่างมั่นใจ"_
เมื่อรันกับข้อมูลจริง 900 บริษัท-ปี เงื่อนไขนี้ **ไม่เป็นจริง** ระบบจึงใส่ทั้งสองชุดโมเดลให้สลับดูได้
เพื่อให้ผู้ตัดสินใจเห็นเองว่าข้อสรุปเปลี่ยนไปแค่ไหนเมื่อเปลี่ยนสมมติฐาน

**ตัวอย่างที่เห็นได้ชัดในระบบ** — บอร์ดสองชุดที่ต่างกันมาก (อายุงานเฉลี่ย 5 ปี vs 18 ปี · กรรมการอิสระ 50% vs 30%):

| | ชุดโมเดล A | ชุดโมเดล B |
|---|---|---|
| บอร์ดชุดที่ 1 | 1.82 | **2.40** |
| บอร์ดชุดที่ 2 | 1.82 | **1.16** |
| แยกความต่างได้ไหม | **ไม่ได้เลย** (ค่าเท่ากันเป๊ะ) | ได้ชัด (ต่างกัน 2 เท่า) |

ชุดโมเดล A ไม่มีตัวแปรอายุงานบอร์ดและกรรมการอิสระอยู่ในสมการ จึงให้ค่าเท่ากันแม้บอร์ดต่างกันสิ้นเชิง

## คณิตศาสตร์ที่ใช้

```
E[OI] = exp( β₀ + Σ βₖ·(xₖ − x̄ₖ) + FE(อุตสาหกรรม) + FE(ปี) )
Var(η) = xᵀ · V · x        →        CI 95% = exp( η ± 1.96·√Var(η) )
```

- โมเดล Negative Binomial (ตัวแปรตามเป็นข้อมูลนับ มีศูนย์ 46% และกระจายเกิน)
- ตัวแปรทุกตัว mean-center ก่อนเข้าสมการ จึงตีความ main effect ได้ตรงแม้มี interaction
- ช่วงความเชื่อมั่นใช้ delta method บนสเกล log — **ยังไม่รวมความไม่แน่นอนของ fixed effect** ช่วงจริงกว้างกว่าที่แสดงเล็กน้อย
- เตือนอัตโนมัติเมื่อค่าที่กรอกอยู่นอกเปอร์เซ็นไทล์ 5–95 ของข้อมูลจริง

## ข้อจำกัดที่ต้องแจ้งผู้ใช้ทุกครั้ง

1. **ไม่ใช่ความสัมพันธ์เชิงสาเหตุ** — โมเดลบอกว่าบริษัทที่มีโครงสร้างแบบนี้มักมีนวัตกรรมเปิดเท่าไร ไม่ได้บอกว่าถ้าเปลี่ยนโครงสร้างแล้วจะได้ผลตามนั้น
2. **วัดการประกาศ ไม่ใช่นวัตกรรมจริง** — ตัวแปรตามนับจากข้อความในรายงานประจำปี
3. **เอกสารฉบับเดียวกัน** — ภาษาผู้บริหารและจำนวนนวัตกรรมมาจากรายงานฉบับเดียวกัน มีความเสี่ยง endogeneity ที่ยังไม่ได้แก้
4. **ห้ามใช้ให้คะแนนบุคคล** — ตัวแปรเพศ อายุ และความเชื่อมโยงทางการเมือง เป็นข้อมูลอ่อนไหวตาม PDPA มาตรา 26 ต้นแบบนี้ออกแบบให้ประเมิน**โครงสร้างองค์กร** ไม่ใช่ประเมินตัวบุคคล
5. ฐานข้อมูลอ้างอิงปกปิดชื่อทั้งหมด — ไม่มีชื่อบริษัทหรือชื่อบุคคลในไฟล์ใดเลย
